# AR寄せ書き — GitHub Pages 暗号化版

## 使うファイル

GitHub Pages にアップロードするファイルは以下の **5つ** です。すべてリポジトリの一番上の階層に置いてください。

- `index.html`
- `main.js`
- `dictionary.js`
- `content.enc.json`（暗号化済み。初回デモ用データが入っています）
- `.nojekyll`（空の隠しファイル。省略可）

`photo-encrypt-local.html` は **PCで写真を暗号化するときだけ使う** 管理ツールです。公開GitHubにアップロードしないでください。

**元の写真・パスワードをGitHubに絶対に置かないでください。** 古い `config.js` / Cloudflare用のサーバーは不要です。

## 公開手順

1. GitHubの既存リポジトリを開く。
2. `Add file` → `Upload files` を選ぶ。
3. 上記5ファイルをリポジトリ直下へドラッグして `Commit changes`。同名ファイルは上書きされます。
4. `Settings` → `Pages` が `Deploy from a branch` / `main` / `/(root)` であることを確認する（以前設定済みならそのまま）。
5. 公開URL `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` をスマホのChrome/Safariで開く。
6. **初回デモパスワード `1111`** を入力し、カメラへのアクセスを許可。
7. マーカーID 23（OpenCV DICT_4X4_50）を映す。検出するとメッセージとデモイラストが表示されます。

初回デモは写真なしです。マーカー画像は `marker23-print.png` / `marker23-print.svg` としてZIPの `印刷用マーカー` フォルダに同梱します。**マーカー画像をGitHubへ置く必要はありません。**

## 写真とメッセージの追加（PCで実施）

1. ZIP内の `photo-encrypt-local.html` をChromeかEdgeで開く。
2. 表示する文字、写真（最大8枚）、新しい閲覧パスワードを入力。**12文字以上推奨**。
3. 「暗号化して content.enc.json を保存」を押す。
4. ダウンロードされた `content.enc.json` をGitHubのリポジトリ直下にアップロード・コミットし、既存ファイルを上書き。
5. サイトを再読み込みして新しいパスワードで確認。

写真はブラウザ内で最大1400pxに縮小し、JPEGに変換した上でAES-256-GCM暗号化します。写真と文字のすべてが一つの暗号化JSONに入ります。

## セキュリティ

- GitHubに置く暗号データは誰でもダウンロードできますが、正しいパスワードがないと通常は復号できません。
- **`1111` は容易に総当たり可能なのでテスト専用です。本番では長くランダムなパスワードへ変更してください。**
- 一度公開した旧ファイルはGit履歴等に残ることがあります。旧版に実際の写真を平文で置いていた場合は履歴からの除去も検討してください。
- パスワードを知る人は写真を保存できます。端末やブラウザが侵害されれば保護できません。
- 公開サイト上に管理ツールを公開する必要はありません。

## 技術的制約

- ライブラリ `js-aruco2` のJSをCDN経由で読み込むため、初回アクセスにはネット接続が必要です。
- スマホのカメラはHTTPSサイト上で利用してください。
- 現在は2D追従表示（6DoFの立体配置ではありません）。完成時24mm角のマーカーでは印刷品質・照明・撮影距離に左右されます。
- 実機スマホの動作はこの環境では未検証です。
